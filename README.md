# ResearchBay

ResearchBay is a web platform designed for researchers and students to manage their research projects, papers, and collaborations. It enables efficient data management and sharing, helping users organize and streamline their research activities.

## Features

- **User Authentication**: Secure user sign-up and login using JWT tokens.
- **Research Paper Management**: Upload, manage, and retrieve research papers.
- **Project Management**: Create and manage research projects with deadlines, tasks, and documents.
- **Database Integration**: Stores research data securely with a MySQL database.
- **Collaboration Tools**: Allows users to collaborate and share research with other users.

## Tech Stack

- **Frontend**: React.js, HTML, CSS, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MySQL
- **Authentication**: JWT (JSON Web Token)
- **Development Tools**: Nodemon, Postman (for API testing)
